# Иллюстрации к конспекту

Все схемы — редактируемый TikZ. Общие стили `gi ...` и неплавающее окружение
`graphillustration` определены в `config.tex`. Подпись и рисунок переносятся
на следующую страницу вместе. Цвет дополнен типом линии, двойным контуром
или цифрой цвета. Стрелки в неориентированных графах показывают обход или
порядок алгоритма только там, где это явно сказано в подписи.

Имена файлов начинаются с номера билета; `notation-*` относится к обозначениям.
Иллюстрации подключены непосредственно из соответствующих `.tex` файлов.
Существующие рисунки в билетах 3, 15–17 сохранены; схема билета 10 вынесена
сюда и дополнена панелью полученного цикла. Схема транзитивности из билета 4
перенесена сразу после доказательства теоремы 4.1 и показывает оба случая.

Сборка из корня: `latexmk main.tex`; результат: `.build/notes-colored.pdf`.

| Исходник | Содержание |
|---|---|
| `notation-subgraphs.tex` | Пример: подграф может опустить ребро $ac$, а порождённый подграф $G[W]$ обязан его содержать. |
| `notation-walks.tex` | Примеры записей обхода. В маршруте повторяется ребро $ab$, в цепи повторяется только вершина $a$. |
| `01-adjacency.tex` | Пример: граф $P_3$ и его матрица в порядке $v_1,v_2,v_3$. |
| `02-split.tex` | Каждый маршрут однозначно разбивается в $v_s$ на префикс длины $p$ и суффикс длины $q$; линии обозначают целые участки. |
| `02-triangle.tex` | Шесть замкнутых маршрутов длины 3 одного треугольника: три начала (двойной контур) и два направления. |
| `03-condensation.tex` | Пример: свёртка КСС даёт конденсацию. Нумерация справа — топологический порядок; все дуги идут слева направо. |
| `04-transitivity.tex` | Оба случая в доказательстве теоремы 4.1: первые встречи на разных путях и на одном пути; выделены два полученных пути без общих рёбер. |
| `04-bridge.tex` | Пример: удаление моста разделяет два треугольника. Пунктир отмечает удалённое ребро. |
| `05-disjoint.tex` | Схема определения: два пути без общих вершин соединяют концы выделенных рёбер $ab,cd$. |
| `05-bypass.tex` | Шаг леммы о двух выходах: обход от $t$ до $y$ избегает $z$. Новые ветви из $t$ идут через $y$ к $s_1$ и через $z$ к $s_2$. |
| `05-block-tree.tex` | Пример: два треугольника и мост — три блока. Справа дерево блоков; двойным контуром отмечены точки сочленения. |
| `06-tree-forest.tex` | Примеры: удаление листа сохраняет дерево; лес может иметь изолированную вершину. |
| `06-extremal.tex` | Пример двух свойств дерева: добавление отсутствующего ребра создаёт цикл, удаление любого ребра разрывает связь. |
| `07-kirchhoff.tex` | Лекционный пример: квадрат с диагональю $13$ и матрица $K=D-A$ в порядке $1,2,3,4$. |
| `07-spanning-trees.tex` | Все восемь остовных деревьев лекционного графа: каждый выбор содержит все четыре вершины и три ребра. |
| `07-minors.tex` | Пример к лемме о минорах: трёх рёбер на четырёх вершинах недостаточно, если они образуют цикл. |
| `08-encode.tex` | Пример кодирования: двойной контур выделяет наименьший лист; после его удаления дописывается метка соседа. Код дерева $(3,3,5,5)$. |
| `08-decode.tex` | Декодирование того же слова: на каждом шаге выбирается наименьшая оставшаяся метка вне суффикса. Неприсоединённые вершины показаны изолированными. |
| `09-splice.tex` | Пример склейки: после возвращения в $x$ обход $C$ продолжается обходом $D$. Стрелки показывают порядок прохождения неориентированных рёбер. |
| `09-auxiliary.tex` | Пример открытого обхода: нечётные $s,t$ становятся чётными после добавления $st$. Для орграфа добавляют именно дугу $t\to s$. |
| `10-hamilton-rewire.tex` | Перестройка гамильтонова пути в цикл: первый участок проходим вперёд, второй — назад. Точками показано ребро пути, не вошедшее в цикл. |
| `10-chvatal-example.tex` | Пример конструкции при $h=2,n=7$: $B\cup D$ — клика, $A$ независимо и соединено только с $B$. После удаления $B$ остаются три компоненты. |
| `11-ore-sets.tex` | Индексные множества в доказательстве Оре: $S\subset T$ в списке вершин по неубыванию степеней. Из смежности следует $d(x)\ge |T|-1$. |
| `11-ore-intersection.tex` | Пример счёта индексов для короткого доказательства ($n=6$): множества $S,T$ из билета 10 обязаны пересечься. Общий индекс позволяет перестроить путь, как на рис.~\ref{fig:10-hamilton-rewire}. |
| `12-insert.tex` | Вставка $x$ заменяет одну дугу двумя. На схеме цикла показан пример с тремя исходными вершинами; на пути возможна также вставка на конце. |
| `12-camion.tex` | Шаг доказательства Камиона: внешним путём $v_i\to a\to b\to v_{i+1}$ заменяем дугу цикла. Схема показывает только используемые дуги турнира. |
| `13-faces.tex` | Пример изменений плоской укладки: удаление немостового $ac$ объединяет две грани; удаление моста $bv$ сохраняет грани и оставляет изолированную вершину $v$. |
| `13-subdivide.tex` | Подразделение ребра новой вершиной степени 2 не меняет укладку и число граней. |
| `14-stereographic.tex` | Стереографическая проекция на экваториальную плоскость $z=0$: показано сечение через $N$, $P$ и центр сферы. Полюс $N$ не имеет конечного образа. |
| `14-outer-face.tex` | Две плоские укладки одного $K_4$: внешними стали разные грани. Метки вершин сохраняют соответствие рёбер. |
| `15-boundaries.tex` | Пример обхода границ: мост $cv$ встречается на границе внешней грани дважды — по одной стороне в каждом направлении. |
| `16-glue.tex` | Пример склейки двух укладок: диски касаются только в общей вершине $a$, их внутренности не пересекаются. |
| `17-proof-map.tex` | Логика достаточности с отсылками к разделам билета. Геометрический перебор в §\,5 дан только в виде схемы, как оговорено в тексте. |
| `18-delete-contract.tex` | Лекционный пример удаления и стягивания одного ребра квадрата. Слева сохраняются четыре вершины, справа концы $u,v$ отождествлены. |
| `18-color-classes.tex` | Два класса раскрасок $G-e$: показано по одному примеру. Цифры — цвета; равенство цветов концов удалённого ребра соответствует стягиванию. |
| `19-root-coloring.tex` | Пример дерева: у корня $k$ цветов, у каждой другой вершины $k-1$ цветов, отличных от родительского. Удаление листа убирает один множитель $k-1$. |
| `20-coefficients.tex` | Пример из текста: многочлен дерева на четырёх вершинах показывает старший коэффициент, число рёбер и число компонент. |
| `20-inclusion-exclusion.tex` | Четыре примера выбора $S\subseteq E(C_4)$. Невыбранные рёбра точечные, компоненты остовного подграфа обведены; каждая компонента даёт один независимый выбор цвета. |
| `21-greedy-order.tex` | Пример порядка жадной раскраски по остову: стрелки указывают от ребёнка к родителю, цифры рядом с вершинами — номера шагов. |
| `21-lovasz-blocks.tex` | Пример конфигурации в лемме Ловаса: два $K_4$ склеены в $z$; штриховые рёбра возвращают вершину $b$. Выбраны внутренние соседи $a,c$ разных крайних блоков. |
| `21-brooks-last.tex` | Схема последнего шага Брукса при $d=4$: показана только окрестность $b$. Цифры — цвета; несмежные $a,c$ заранее получили одинаковый цвет. |
